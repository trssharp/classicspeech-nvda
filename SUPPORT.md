# Support

## Where to ask for help

Use the repository's GitHub Issues page for ordinary installation, configuration, and reproducible behavior problems. Start with the bug-report template so that reports contain the information needed to investigate them.

For a useful report, include:

1. ClassicSpeech version;
2. NVDA version and Windows version;
3. active synthesizer and voice or variant;
4. the active ClassicSpeech settings or Voice Profile category, when relevant;
5. exact keystrokes or other reproduction steps;
6. expected speech and actual speech; and
7. a small relevant NVDA log excerpt with personal information removed.

## Privacy and sensitive information

Do not post passwords, API keys, access tokens, private documents, personal account data, full unredacted NVDA logs, or security-vulnerability details in a public issue.

For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Scope

ClassicSpeech support covers the released add-on and its documented settings. It does not provide general Windows, NVDA core, browser, or third-party synthesizer support. A report that shows a ClassicSpeech-specific regression or interaction is still welcome.
