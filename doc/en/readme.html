ClassicSpeech User Guide

ClassicSpeech is an NVDA add-on that lets you choose what NVDA says about controls and objects, and in what order. It also adds voice profiles, JAWS-style speech and sound schemes, web page tools, a speech history, and optional text and number processing.

This guide describes every ClassicSpeech setting and command. Setting names are written exactly as NVDA speaks them in the dialogs.

Opening this guide

You can open this guide in two ways:

  • From the Add-on Store: press NVDA+N to open the NVDA menu, then choose Tools, then Add-on Store. Go to the Installed add-ons tab (Control+Tab moves between tabs) and move to ClassicSpeech in the list. Press the Applications key or Shift+F10, then choose Help.
  • With a gesture: assign a gesture to the Opens the ClassicSpeech user guide command. It has no gesture until you assign one. See Assigning gestures.

The guide opens in your default web browser. In browse mode, press H to move from heading to heading, or 2 to move between the main sections.

This guide is in English. If a translation for your NVDA language is added later, NVDA opens it instead.

Getting started

ClassicSpeech starts working when NVDA restarts after installation. It supports NVDA 2025.1 through 2026.2.

Its settings are in the NVDA menu: press NVDA+N, then choose Preferences, then ClassicSpeech. The ClassicSpeech submenu has six items:

  • General Settings...: how much ClassicSpeech says about objects, token order and timing, text and number processing, menus, key names, shortcut keys, and other speech options. See General Settings.
  • Web / Browse Mode Settings...: browse mode, web element reporting, Page Summary and Microsoft Edge notifications. See Web / Browse Mode Settings.
  • Voice Profiles...: different voice settings for different kinds of speech. See Voice Profiles.
  • Speech and Sound Schemes...: sounds and voices for object types, states, formatting and web elements, and sounds to play instead of NVDA's own. See Speech and Sound Schemes.
  • Check for Updates...: look for a newer ClassicSpeech and install it. See Updating ClassicSpeech.
  • Reset All ClassicSpeech Settings...: delete every ClassicSpeech setting and put back the NVDA settings ClassicSpeech changed. See Resetting ClassicSpeech.

These commands work as soon as ClassicSpeech is installed:

  • NVDA+Tab: speak the current object. Press twice quickly to spell it and copy it to the clipboard.
  • NVDA+E: say the current dialog's default button.
  • NVDA+Shift+U: summarize the current web page.
  • Shift+F11, Shift+F12, Control+Shift+F11, Control+Shift+F12, F12 and NVDA+Shift+H: review, copy and open the speech history.

Every command is listed in Commands and gestures.

How the settings dialogs work

  • The General Settings and Web / Browse Mode Settings dialogs start with a Categories list. Choose a category with the arrow keys, then press Tab to reach its options.
  • In those two dialogs, most changes take effect as soon as you make them, so you can hear the difference before you save.
  • OK saves your changes and closes the dialog. Apply saves them and leaves the dialog open.
  • Cancel, Escape, or closing the window puts back the settings you had when you opened the dialog, or when you last pressed Apply.
  • Reset buttons work immediately, and Cancel does not undo them, so ClassicSpeech asks you to confirm first.

ClassicSpeech keeps its own settings in its own file, not in NVDA's configuration file, so they stay the same when an NVDA configuration profile is active. They are saved whenever NVDA saves its configuration, for example when you press NVDA+Control+C or when NVDA exits, and NVDA+Control+R (Revert to saved configuration) reloads them. See Where ClassicSpeech keeps its settings.

Some pages also show options that belong to NVDA itself, such as Document Reading / Proofing and Browse Mode. NVDA saves those in its own configuration, as usual. Before ClassicSpeech changes one of NVDA's settings for the first time, it records the value NVDA had, so resetting or removing ClassicSpeech can put it back.

General Settings

Open this dialog from the NVDA menu: Preferences, then ClassicSpeech, then General Settings. The dialog is called ClassicSpeech Settings, and its Categories list has eleven pages, described below in order.

Next to the OK button there is a reset button whose name depends on the page: Reset Profile Now on Verbosity, Reset Tokens to Defaults Now on Token Editor, and Reset Key Labels to Defaults Now on Key Labels. Other pages have no reset button.

Verbosity

Choose how much ClassicSpeech says about each object. A verbosity profile is a named set of these choices.

  • Active profile: Beginner, Intermediate or Advanced. The profile you choose becomes active, and the rest of this page changes that profile. Default: Beginner.
  • Spoken object details: a checklist of Name, Role, State, Description and Tooltip. Checked details are spoken. Press Space to check or clear one.
  • Position announcements: whether to say where an item is in its list or group, such as "3 of 10".
    • Off.
    • Announce only first item: say the position only for the first item you reach in a list or other container.
    • Announce on every move.
  • Read edit field contents when focused: when checked, moving to an edit field speaks its current line, or "blank" when it is empty, as NVDA does. Clear it to hear only selected text. Default: checked for every profile.

Reset Profile Now returns the selected profile to these defaults.

Token Editor

ClassicSpeech speaks an object as a series of tokens: its name, role, value, state, position, description and hotkey. The Token Editor applies to every verbosity profile.

  • Spoken token sequence: the order tokens are spoken in. Select a token and press Control+Up Arrow or Control+Down Arrow to move it. Default order: Name, Role, Value, State, Position, Description, Hotkey.
  • Roles and States: every role word, such as "button" or "check box", and every state word, such as "checked" or "expanded", that NVDA can speak. In either list:
    • Space mutes or unmutes the word. A checked item is spoken; a cleared item is muted.
    • F2 renames it, for example "btn" instead of "button".
    • Delete removes the rename.
    • Shift+F10 or the Applications key opens a menu with the same actions.

Reset Tokens to Defaults Now clears every rename and mute and restores the default order.

Speech Timing

Set the short silences ClassicSpeech places between tokens.

  • Global pause: the pause between tokens. Choose Off, or 80 to 1000 milliseconds. Default: 80 ms.
  • Pause placement: Before each token or After each token. Default: Before each token.
  • Name pause, Role pause, Value pause, State pause, Position pause, Description pause and Hotkey pause: a different pause for one token. Choose Use global, Off, or a length. Default: Use global.
  • Pause after final spoken token: also pause after the last token. Default: checked.

Text Processing

These options change text before it reaches your synthesizer.

  • Announce new lines during Say All: speak a message at each line break while NVDA reads continuously. New line message sets the words. Default: off, with the message "new line".
  • Split mixed-case words, such as SayAll into Say All. Default: off.
  • Suppress dashes inside words, such as sister-in-law: read the parts as separate words without saying "dash". Default: off.
  • Spell alphanumeric data: spell words that mix letters and digits, such as a part number.
    • Off (default).
    • Spell mixed letters and numbers.
    • Spell mixed letters and numbers phonetically, with words such as "Alpha" and "Bravo" for the letters.
  • List item state reporting: whether you hear "selected" and "not selected" as you move to list items, tree view items, menu items, and table rows and cells. When you select or unselect the item you're on, for example with Control+Space in a list of files, you always hear its name and "selected" or "not selected", whatever this option says.
    • NVDA native: as NVDA speaks them.
    • Say not selected: speak only "not selected". This is the default.
    • Say none.
    • Say selected: speak only "selected".
    • Say both.
  • Repeated characters: how a run of the same punctuation mark is read, such as a line of dashes.
    • NVDA native: leave it to NVDA and your synthesizer.
    • 3 repeated characters: read at most three of them. This is the default.
    • 4 repeated characters, 5 repeated characters and 6 repeated characters: say each symbol by name, up to that many times.
    • All repeated characters: say every symbol by name.
    • Count repeated characters and spaces: say how many there are, such as "5 dashes" or "4 spaces". This helps you follow indentation.

Number Processing

Number Processing leaves numbers to NVDA and your synthesizer until you change it. It changes only standalone numbers and the dates, prices, ordinals and phone numbers described below. Times, codes and text that mixes numbers and letters stay unchanged.

  • Number processing: how standalone whole numbers are read, with or without commas. Using 1234 as the example:
    • NVDA native: your synthesizer decides. This is the default.
    • Single digits: "one two three four".
    • Pairs: "twelve thirty four".
    • Full numbers: "one thousand two hundred thirty four".
  • Speak single digits if number contains: read long numbers one digit at a time, whatever Number processing is set to. Choose NVDA native (default), Five or more digits, Six or more digits, Seven or more digits, or Eight or more digits.
  • Phone number processing: NVDA native (default), or Grouped digits, which reads common U.S. phone numbers in groups. For example, 555-1212 becomes "five five five, one two one two".
  • Use friendly toll-free prefixes: with Grouped digits, say 1-800 as "one eight hundred". Default: checked.
  • Currency processing: NVDA native (default), or Dollars and cents: $5.25 becomes "five dollars and twenty five cents".
  • Ordinal processing: NVDA native (default), or Ordinals as words: 22nd becomes "twenty second".
  • Numeric date processing:
    • NVDA native (default).
    • Some: read complete dates. For example, 9/18/2026 becomes "September eighteenth, twenty twenty six".
    • Full: also read dates without a year, such as 9/18.
  • Numeric date format: the order of the parts in a numeric date: Month day year (default), Day month year, or Year month day.
  • Recognize ISO year-first dates: also read strict year-first dates such as 2026-09-05, whatever the date format. Default: checked.
  • Use Windows locale for date format: use the date order from your Windows regional settings. If Windows uses an order ClassicSpeech doesn't support, Numeric date format is used. Default: off.

Document Reading / Proofing

This page shows options from NVDA's own Document Formatting settings, so you can change them without leaving ClassicSpeech. Changing them here is the same as changing them in NVDA's Document Formatting settings.

  • Font group: Font name, Font size, Font attributes (Off, Speech, Braille, or Speech and braille), Superscripts and subscripts, Emphasis, Highlighted (marked) text, Style, Colors, and Report transparent color values, which is available when Colors is checked.
  • Document information group: Comments, Bookmarks, Editor revisions, and Spelling or grammar errors, a checklist of the ways NVDA reports them.
  • Pages and spacing group: Pages, Line numbers, Line indentation reporting (Off, Speech, Tones, or Both Speech and Tones), Ignore blank lines for line indentation reporting, Paragraph indentation, Line spacing and Alignment.
  • Table information group: Tables, Headers (Off, Rows and columns, Rows, or Columns), Cell coordinates, and Cell borders (Off, Styles, or Both Colors and Styles).
  • Advanced group: Report formatting changes after the cursor (can cause a lag).

To give formatting its own voice or sound, use the Document and web formatting voice profile or Speech and Sound Schemes.

Menus

Choose what ClassicSpeech says when menus open and close. Each announcement has a checkbox and an edit field for its words.

  • Announce menu open, with Menu open message. Default: checked, "Entering menu".
  • Announce menu close, with Menu close message. Default: checked, "Leaving menu".
  • Announce menu bar focus, with Menu bar focus message. Default: checked, "Menu bar".
  • Announce leaving menu bar, with Menu bar leave message. Default: off, "Leaving menu bar".

Key Labels

Change how keys are spoken when NVDA echoes what you type or announces keys you press. NVDA's input help, NVDA+1, is not affected.

The Key labels list has every key NVDA can name, plus letters, digits and punctuation keys. It works like the Token Editor lists: Space mutes or unmutes a key, F2 renames it, Delete removes the rename, and Shift+F10 opens a menu with the same actions.

Reset Key Labels to Defaults Now clears every rename and mute.

Hotkeys

Choose where ClassicSpeech speaks keyboard shortcuts and how they sound. These settings apply to every verbosity profile. The current object command, NVDA+Tab, always includes a shortcut when NVDA provides one.

  • Speak hotkeys in: a list of checkboxes, Menus and Dialogs. Check both, check one, or clear both to turn shortcut speech off. Arrow to a line and press Space to change it, the same way NVDA's Document Formatting page offers Spelling or grammar errors. Default: both checked.
  • Shortcut formatting:
    • Native shortcut as is, such as "Ctrl+S". This is the default.
    • Expanded without plus, such as "Control S".
    • Abbreviated without plus, such as "Ctrl S".
  • Which shortcuts to speak: a list of checkboxes, Access keys (the underlined letters you use with Alt) and Command shortcuts (such as Control+S). Clearing both speaks no shortcut at all. Default: both checked.
  • For simple dialog Alt shortcuts, speak only the access key letter: in dialogs, say "N" instead of "Alt+N". Default: off.

Misc

  • Announce default button in dialogs: add "default" when focus reaches a dialog's default button, as in "OK, default, button", or "Open, default, split button" in a file dialog. The default button is the one Enter presses after you change something in another control of the dialog; see Default button: NVDA+E. A button that counts as the default only while it has focus is not announced as the default. Default: off.
  • Guess object position information when unavailable: NVDA's own setting. It estimates positions such as "3 of 10" when an application doesn't report them. Default: off.
  • Insert+Tab reports: what the NVDA+Tab command reports.
    • NVDA native: run NVDA's own report current focus command.
    • Focused object: ClassicSpeech's announcement of the focus. This is the default.
    • Navigator object: ClassicSpeech's announcement of the navigator object.
  • Object navigation processing: when checked, ClassicSpeech applies your verbosity settings to NVDA's object navigation commands. When cleared, those commands speak as NVDA does, in the Review and object navigation voice. Default: off.
  • Prevent automatic speech interruptions: when checked, speech that NVDA starts on its own, for example when focus or the active window changes, waits for current speech to finish instead of cutting it off. Default: off.
  • Give ClassicSpeech messages priority over NVDA speech: when checked, the messages ClassicSpeech speaks itself are spoken right away, ahead of NVDA's speech, and NVDA's own speech can't cut them off. For example, the speech hook loaded message is no longer cut off when NVDA reports the focus after it starts. Speech NVDA had started continues after the message, and speech NVDA starts while the message plays waits for it. Pressing a key still stops a message, as it stops any speech; so does a key on a braille display or a touch gesture. Default: off.
    • The messages are: the speech hook loaded message, Page ready and page summaries, the speech history, the default button, speech and sound scheme, update and user guide messages, and your own browse mode, focus mode and Microsoft Edge notification messages.
    • The object ClassicSpeech speaks for NVDA+Tab is not a message, and speaks as before.
  • Speech interrupt for typed characters and Speech interrupt for Enter key: NVDA's own keyboard settings, shown here for convenience. Default: both checked.

Advanced

  • Enable ClassicSpeech speech processing hook: the main switch for ClassicSpeech's speech changes. When cleared, NVDA speech passes through without ClassicSpeech processing, but ClassicSpeech commands still work. Default: checked.
  • Speak a message when the speech hook loads, with Speech hook loaded message: say a message when ClassicSpeech starts processing speech, for example after NVDA starts. Default: off, "ClassicSpeech hook loaded".
  • Enable ClassicSpeech diagnostic logging: write detailed ClassicSpeech entries to the NVDA log. It slows speech, so turn it on only to record a problem, then turn it off. Default: off.
  • Check for ClassicSpeech updates automatically: once a day, shortly after NVDA starts, ask GitHub whether a newer ClassicSpeech has been released, and tell you only if there is one. See Updating ClassicSpeech. Default: checked.

Web / Browse Mode Settings

Open this dialog from the NVDA menu: Preferences, then ClassicSpeech, then Web / Browse Mode Settings. Its Categories list has four pages.

Browse Mode

This page shows NVDA's own browse mode settings, plus two ClassicSpeech additions.

  • NVDA's settings: Maximum number of characters on one line, Number of lines per page, Use screen layout (when supported), Enable browse mode on page load, Automatic Say All on page load, Automatic focus mode for focus changes, Automatic focus mode for caret movement, Trap all non-command gestures from reaching the document, Touch navigation elements (available on touch screens), and Load Chromium virtual buffer when document busy.
  • Audio indication of focus and browse modes: NVDA's setting that plays a sound when you switch between browse mode and focus mode. Default: checked. When you clear it, NVDA speaks the mode's name instead, and ClassicSpeech makes two fields available:
    • Browse mode message and Focus mode message: the words spoken for each mode. They start as NVDA's own "Browse mode" and "Focus mode". Clear a field to go back to NVDA's wording.
  • Reduce repeated heading levels on continuation lines, in the Experimental heading presentation group: when a heading wraps onto more than one line, stop repeating "heading level 2" on each line. Default: off.

Web Element Reporting

These are NVDA's own settings for elements in documents and web pages, gathered from NVDA's Document Formatting and Braille settings: Report 'has details' for structured annotations, Report aria-description always, Include layout tables, Headings, Links, Link type, Graphics, Lists, Block quotes, Groupings, Landmarks, Articles, Frames, Figures, Clickable, and Braille report live regions.

Page Summary

Page Summary counts elements on a web page and speaks the result, for example "4 headings, 2 landmarks, 37 links." Press NVDA+Shift+U in browse mode to hear it. It counts without moving your position on the page.

  • Notify when page is ready: speak a message when a page finishes loading. Page ready message sets the words. Default: off, "Page ready".
  • Page-load summary: whether ClassicSpeech speaks the summary on its own when a page opens.
    • NVDA native, no summary. This is the default.
    • Summary after page is ready: NVDA reads the page as usual, then ClassicSpeech speaks the summary.
    • Replace initial page speech with summary: ClassicSpeech speaks the summary instead of what NVDA normally says when a page opens.
  • Automatic page-entry summary delay: how long to wait before the automatic summary, from No additional delay to 5 seconds. Available when Page-load summary is not NVDA native. Default: 2 seconds.
  • Page Summary choices: a checklist of what the summary includes: Title (the page title, spoken first), Annotations, Buttons, Combo boxes, Landmarks, Edit fields, Form fields, Graphics, Headings, Links, Lists, Frames, Embedded objects, Block quotes, Radio buttons, Separators, Tables, Errors and Check boxes. Checked by default: Buttons, Landmarks, Form fields, Headings, Links and Tables.

Types with none on the page are left out. If nothing is found, you hear "No selected element types found."

Microsoft Edge Notifications

Choose which Microsoft Edge notifications are spoken, such as download progress or zoom changes. Each notification type in the Microsoft Edge notifications list is either announced or suppressed:

  • Space switches between Announce and Suppress.
  • F2 sets your own message for that notification.
  • Delete goes back to Edge's own message.
  • Shift+F10 opens a menu with these actions.

Announced by default: Start download, Download completed, Edge update, Zoom changes, Remove suggestion, Site permission or content setting, and Excel autofill suggestion. The other types, such as Page loading, Back and New tab, are suppressed by default. Edge notifications that are not in the list keep NVDA's normal handling.

Changing a category's voice

  1. In the Voice profiles list, select a category.
  2. Press Tab to move through the settings your synthesizer offers, such as Voice, Variant, Rate, Pitch, Volume and Inflection. The settings depend on your synthesizer.
  3. Change the settings that should be different for that category. Each category starts with your current NVDA voice settings.
  4. To hear the result, change Preview text if you like, then press Preview selected profile.
  5. Press OK to save, or Cancel to discard your changes. An Apply button appears after you change something.
  • ClassicSpeech saves only the settings you change, and keeps them separately for each synthesizer.
  • ClassicSpeech never changes your NVDA voice settings. It uses a category's settings while speaking that kind of speech, then returns to your voice.
  • While a settings dialog of NVDA or ClassicSpeech, or the NVDA menu, is open, a category that uses another voice speaks with your own NVDA voice. NVDA treats its configuration profiles the same way, so the settings you change there, including your voice settings, are saved as you set them. Preview still uses the category's voice. A category that changes only rate, pitch or volume keeps doing so.
  • If you change an NVDA setting while a category's voice is still speaking, for example with a toggle command, your change is kept.
  • Reset all Voice Profile overrides removes your changes to the first five categories for the active synthesizer, after asking you to confirm. Document and web formatting voices are not affected.

Sharing voice profiles

  • Export voice profiles... saves the first five categories, for every synthesizer you have set them up for, in one file whose name ends in .classicspeech-voices. Send the file to someone, or keep it as a backup.
  • Import voice profiles... reads such a file. It replaces only the synthesizers and categories in the file; your other voice profiles stay as they are. Press OK or Apply to keep the imported profiles, or Cancel to discard them.

Voice profiles belong to a synthesizer, so imported profiles for a synthesizer you aren't using wait until you switch to it. A voice that isn't installed on your computer can't be used. Document and web formatting voices are part of Speech and Sound Schemes, so share them by exporting a scheme.

Document and web formatting voices

When you select Document and web formatting in the Voice profiles list, the rest of the dialog lists every formatting option and web element NVDA can report. A voice set here is used for the announcement and for the text itself. For example, bold words are read in the bold voice, and a link's text in the link voice.

The items are grouped as follows:

  • Font and text formatting: font name and size changes, bold, italic, underline, strikethrough, hidden text, superscript and subscript, emphasis, highlighting, style changes and colors.
  • Specific font names: every font installed on your computer, plus fonts you add.
  • Specific font sizes: common sizes from 8 to 72 points, plus sizes you add.
  • Specific styles: styles you add, such as Heading 1 or Quote.
  • Document information: comments, bookmarks, editor revisions, and spelling and grammar errors.
  • Pages and spacing: page and section numbers, columns, breaks, line numbers, indentation, line spacing, alignment, and list bullets and numbers.
  • Table information: tables, cell coordinates, headers and cell borders.
  • Elements (documents and web pages): headings and each heading level, links (including visited and same-page links), graphics, lists and list items, block quotes, groupings, articles, frames, figures, captions, clickable elements, forms and math.
  • Landmarks and regions: each landmark type, and regions.

Select an item, check Use a custom voice for this item, and change its settings. The controls are the same as in Speech and Sound Schemes: see Giving an item a voice. Here, Reset this item removes only the item's voice.

These voices are part of the active speech and sound scheme, so they also appear in Speech and Sound Schemes. They are used while Enable speech and sound schemes is checked, which is the default. Sounds for these items are set in Speech and Sound Schemes.

Speech and Sound Schemes

Speech and Sound Schemes work like the JAWS Speech and Sounds Manager. You can give any object type, object state, window class, unknown object, unlabeled graphic, formatting option or web element:

  • a WAV sound, played with the announcement or instead of it;
  • its own voice, on your synthesizer or another installed synthesizer.

You can also replace the sounds NVDA itself plays, such as the browse mode and focus mode sounds or the Remote Access sounds, with sounds of your own. See Replacing NVDA's own sounds.

Items you don't change keep NVDA's normal speech and sounds. Sounds and voices work with focus changes, object navigation, the review cursor, say all, browse mode and the mouse.

In a document, an item's sound and voice follow the text it describes, however you read it: character by character, word by word, line by line, by sentence, by paragraph and in say all. You hear the change on the words that carry the formatting, not on the whole line. Reading the same underlined phrase by word and then by line sounds the same.

This does not depend on NVDA's Document Formatting settings. If you ask a scheme for underlined text but have NVDA's Font attributes announcement turned off, ClassicSpeech asks NVDA for the formatting it needs and NVDA still says nothing about it: you hear the scheme's voice or sound, not the word "underlined". Your Document Formatting settings are not changed, and NVDA announces exactly what you told it to announce.

A sound set for a formatting option or an element is played where that formatting or element begins in the text, once for each run of it, and again on the next line. A sound set for an object type or a state is played where the object starts.

An object's states are part of the object. NVDA never speaks some of the states it knows about, such as Focusable, Checkable and Selectable, so an item for one of those is used for any object in that state rather than for a word NVDA would say. An object's type comes first: if you set a sound for both check box and checked, you hear the check box sound. A negated state such as not checked is different: it is used where NVDA says those words, because that is the only place the absence of a state means anything.

A voice that only changes the rate, the pitch or the volume is normally sent to your synthesizer as a speech command, which keeps speech flowing. Some synthesizers act on only some of those commands; BestSpeech, for example, acts on pitch and ignores rate and volume. ClassicSpeech checks what your synthesizer will act on, and where a command would be ignored it changes the synthesizer's own settings instead. That way is always heard, but it takes effect at a speech boundary, so it can add a very short pause where the formatting starts.

Rate, pitch and volume are relative to your own settings. If your synthesizer's pitch is already near the bottom of its range, choosing a slightly lower pitch for an item is a slight change; pick a value further from your own, or a different voice, when you want an item to stand out.

Open this dialog from the NVDA menu: Preferences, then ClassicSpeech, then Speech and Sound Schemes. Its buttons are OK, Cancel and Apply.

Turning schemes on and choosing a scheme

  • Enable speech and sound schemes: turns every scheme sound and voice on or off, including document and web formatting voices. Default: checked.
  • Active scheme: the scheme in use. A scheme is a named set of sounds and voices. ClassicSpeech starts with one scheme, called Default.
  • New scheme... creates an empty scheme, Copy scheme... copies the active one, Rename scheme... renames it, and Delete scheme deletes it after asking you to confirm.

Two commands do the same without opening the dialog: Turns ClassicSpeech speech and sound schemes on or off, and Switches to the next ClassicSpeech speech and sound scheme. They have no gestures until you assign them.

Below the scheme buttons are Export scheme..., Import scheme... and Open schemes folder, described in Where schemes are kept and Sharing schemes.

Where schemes are kept

Each scheme, including Default, is a folder inside a folder called Schemes. For an installed copy of NVDA, that is %APPDATA%\nvda\ClassicSpeech\Schemes, in NVDA's user configuration folder. Press Open schemes folder to open it in File Explorer.

  • A scheme's folder has the scheme's name, with characters Windows doesn't allow in folder names replaced by an underscore.
  • Inside it, scheme.json holds the scheme's settings, and the Sounds folder holds its sounds.
  • When you press OK or Apply, ClassicSpeech copies each sound you chose into the scheme's Sounds folder. The scheme keeps working if you later move or delete the original file.
  • Renaming or deleting a scheme in the dialog renames or deletes its folder when you press OK or Apply.

Earlier versions of ClassicSpeech kept schemes inside NVDA's configuration. They are moved into folders the first time this version starts, and nothing else changes.

Sharing schemes

  • Export scheme... saves the active scheme, with all of its sounds, voices and added entries, in one file whose name ends in .classicspeech-scheme. If a sound file can't be found, ClassicSpeech lists the sounds it left out.
  • Import scheme... reads a scheme file someone sent you and adds it as a new scheme, which becomes the active scheme. If you already have a scheme with that name, a number is added, such as "Default 2". Press OK or Apply to keep it, or Cancel to discard it.

A voice in a shared scheme works only with the same synthesizer, and the same voice, on the other computer.

Finding an item

  • Search items: type part of a name, such as "bold" or "link", to show only matching items.
  • List: All items, or Only items with a sound or voice, to review what you have changed.
  • Scheme items: a tree of categories. Press Right Arrow to open a category and Left Arrow to close it. An item's name says what it uses, for example "Bold (sound, voice)" or "Link (sound only)".
  • Item details: a read-only field describing the selected item, including what its voice covers.

The categories are:

  • Font and text formatting, Specific font names, Specific font sizes, Specific styles, Document information, Pages and spacing, Table information, Elements (documents and web pages), and Landmarks and regions. These are the same items as the Document and web formatting voices.
  • Object types (control types and roles): every NVDA object type, such as button, check box, link or unknown.
  • Object states: every NVDA state, such as checked, selected or expanded, and opposite states such as "not checked".
  • Unknown and unlabeled objects: unknown objects, graphics without a label, and graphics.
  • Window classes: window classes you add.
  • NVDA sounds: the sounds NVDA itself plays, each named after the event it reports, such as Switching to browse mode or Remote Access: clipboard received. See Replacing NVDA's own sounds.

Giving an item a sound

  1. Select the item in the tree.
  2. Press Browse for sound... and choose a WAV file. The Sound file field shows its location.
  3. Press Play sound to hear it.
  4. In When playing the sound, choose Also speak the announcement, or Do not speak the announcement (sound only).

Remove sound removes the item's sound. Only WAV files are supported. Short sounds work best, because a sound plays at the same moment as the announcement.

Giving an item a voice

  1. Select the item and check Use a custom voice for this item.
  2. In Synthesizer, keep Active synthesizer, or choose Other synthesizers... to pick another installed synthesizer.
  3. Change the voice settings that appear, such as Voice, Rate or Pitch.
  4. Press Speak a voice preview to hear it.

Reset this item removes the item's sound and voice.

While a settings dialog of NVDA or ClassicSpeech, or the NVDA menu, is open, an item whose voice uses another voice or synthesizer speaks with your own NVDA voice, and Speak a voice preview still uses the item's voice. See Changing a category's voice.

The active synthesizer switches voices fastest. Another synthesizer has to be loaded each time the item is spoken and unloaded afterwards, which adds a noticeable delay. If ClassicSpeech can't load it, the item keeps using your active synthesizer.

Replacing NVDA's own sounds

NVDA plays sounds of its own for some events, from the waves folder in its program folder: when it switches between browse mode and focus mode, when it starts and exits, when auto-suggestions appear and close, for spelling errors, when it logs an error, when the screen curtain turns on or off, and for Remote Access. The NVDA sounds category lists each of them by the event it reports. Item details names the file NVDA plays and the NVDA option that turns that sound on.

  1. Select the event in the NVDA sounds category.
  2. Press Play sound to hear NVDA's own sound.
  3. Press Browse for sound... and choose a WAV file. Play sound now plays your file.
  4. Press OK or Apply.

From then on, NVDA plays your sound instead of its own while Enable speech and sound schemes is checked and that scheme is active. Like every scheme sound, your file is copied into the scheme's folder, in %APPDATA%\nvda\ClassicSpeech\Schemes for an installed copy of NVDA, and only a sound in that folder replaces one of NVDA's. NVDA's own files are never changed.

  • Remove sound or Reset this item, then OK or Apply, brings back NVDA's own sound. So does turning schemes off, or choosing a scheme that doesn't replace that sound.
  • When the active scheme replaces none of NVDA's sounds, NVDA plays its sounds exactly as it always has.
  • Your sound plays only when NVDA would play its own. If an NVDA option such as Audio indication of focus and browse modes is off, NVDA plays no sound for that event, and neither does your scheme.
  • If NVDA can't play your file, it tries its own sound instead. This also applies to startup, shutdown and Windows sign-out sounds. If the native sound also fails, ClassicSpeech does not keep retrying.
  • Unloading ClassicSpeech stops its sound replacements without removing another add-on's sound handler. Reloading ClassicSpeech enables only its new sound handler; any old handler retained by another add-on stays inactive.
  • These sounds have no voice, and When playing the sound doesn't apply to them.
  • When another computer controls this one through Remote Access, NVDA sends it the sounds it plays by their file names. A sound your scheme plays instead is a file only this computer has, so the controlling computer doesn't hear it.

NVDA's start sound is different, because NVDA plays it before add-ons load. While the active scheme has a sound for NVDA starts, ClassicSpeech turns off Play sounds when starting or exiting NVDA in NVDA's General settings, so NVDA doesn't play its own start sound first. ClassicSpeech then plays the start sound itself as soon as it loads, a moment later than NVDA would, and the exit sound, yours or NVDA's, when NVDA exits. When the scheme no longer has a start sound, or when you disable, remove or reset ClassicSpeech, it turns that option back on. If that option was already off, NVDA plays no start or exit sound, and neither does ClassicSpeech.

Adding fonts, sizes, styles and window classes

  • Add font name...: add a font, such as Arial, to Specific font names.
  • Add font size...: add a size in points, such as 13 or 10.5, to Specific font sizes.
  • Add style name...: add a style exactly as NVDA reports it, such as Heading 1 or Quote, to Specific styles.
  • Add window class...: add a window class to Window classes. The field starts with the class of the object you were on before opening the dialog, so move to that control first, then open Speech and Sound Schemes.
  • Remove added entry: remove a font, size, style or class you added, together with its sound and voice.

Added entries belong to the active scheme and travel with it when you export it. A new scheme starts with the active scheme's added entries.

Current object, default button and page summary commands

Current object: NVDA+Tab

ClassicSpeech replaces NVDA's report current focus command with its own announcement. It uses your verbosity settings and always includes the object's shortcut key when there is one. Press NVDA+Tab twice quickly to spell the announcement and copy it to the clipboard.

Insert+Tab reports, in General Settings on the Misc page, chooses whether the command reports the focused object or the navigator object, or runs NVDA's own command. When the speech processing hook is off, NVDA's own command runs.

Default button: NVDA+E

Says the default button of the current dialog: the button that Enter presses after you change something in one of the dialog's other controls, for example "Default button OK". If there isn't one, you hear "No default button".

ClassicSpeech names the dialog's default button even while focus is on another button. For example, on the Cancel button of a file dialog you hear "Default button Open". Pressing Enter on a button still presses that button.

ClassicSpeech finds the default button in:

  • NVDA's and ClassicSpeech's own dialogs. In NVDA's settings dialogs this is OK, which Enter presses from any control.
  • Standard Windows dialogs, such as Open and Save As in LibreOffice, Notepad and most other programs, message boxes and property sheets. A split button, such as the Open button of the file dialog, counts too.
  • Dialogs of other programs whose buttons report the default state, such as LibreOffice's own dialogs and Microsoft Office dialogs.
  • Web forms: the button that Enter presses in the form's edit fields, when the browser reports it.

In many programs, a button counts as the default only while it has focus, so the dialog's own default button can't be read while you are on another button. ClassicSpeech remembers it from when focus was in another control of the dialog. If focus has only been on buttons since the dialog opened, you hear, for example, "No default button known. Enter presses Cancel". Move to an edit field or another control and press NVDA+E again.

When neither Windows nor the program reports a default button, ClassicSpeech looks at the dialog's buttons on the screen, the way a sighted person tells them apart: many dialogs fill their default button, or draw its border, in the accent color. If exactly one button stands out that way, you hear, for example, "Default button Save, by appearance". This check needs the dialog on the screen. While NVDA's Screen Curtain is on, ClassicSpeech can't see the buttons, and you hear "No default button found. Turn off Screen Curtain so ClassicSpeech can check how the buttons look." ClassicSpeech only compares the colors of the buttons; nothing is saved. Focus speech never uses this check.

Page summary: NVDA+Shift+U

In browse mode, speaks the element counts chosen on the Page Summary page. Elsewhere, you hear "Page summary is not available here."

Updating ClassicSpeech

ClassicSpeech can check for a newer version on the GitHub page it comes from: the releases of the page shown as its homepage in NVDA's Add-on Store. A copy of ClassicSpeech without a GitHub homepage can't check. Check for Updates says so, and automatic checks don't run.

  • To check now, press NVDA+N, then choose Preferences, then ClassicSpeech, then Check for Updates.... You can also assign a gesture to the Checks for ClassicSpeech updates command. You hear "Checking for ClassicSpeech updates", then a message says whether ClassicSpeech is up to date.
  • With Check for ClassicSpeech updates automatically checked on the Advanced page, ClassicSpeech checks once a day, about 30 seconds after NVDA starts. It says nothing unless there is an update.

When a newer version is available, a dialog opens. It says which version you have and which version is available, and then holds the new release's notes in a box called What's new.

That box is a read-only edit box, so the notes are text you can read rather than a message that is spoken once. Focus starts in it, so you can read straight away:

  • Read it with the arrow keys, by line, by word or by character, and with Home, End, Page Up and Page Down. NVDA's review commands work in it as they do in any text field.
  • Select with Shift and the arrow keys, or Control+A for everything, and copy with Control+C.
  • Nothing you type changes it, and nothing you do in it changes what will be installed.
  • Press Tab to reach the buttons, and Escape to close the dialog without installing anything.

Then choose one of its buttons:

  • Download and install: ClassicSpeech downloads the new add-on file and checks it against the checksum file published with it. If they don't match, the file is deleted and nothing is installed. Then NVDA asks you to confirm the installation, as it does for any add-on file, and offers to restart NVDA.
  • Not now: nothing is downloaded. An automatic check asks again the next day.

If a release has no add-on file to install, the same dialog shows its notes and tells you where to download it, with only a Close button.

Updating keeps all your ClassicSpeech settings, voice profiles and schemes. To check for updates, ClassicSpeech contacts GitHub (api.github.com and github.com). It sends only what any web request sends, plus the ClassicSpeech version, and nothing about you or your settings.

What's new in the Add-on Store

Every ClassicSpeech release also tells NVDA what is new in it, and NVDA 2026.1 and later show those notes in the Add-on Store. Press NVDA+N, then choose Tools, then Add-on Store, and move to ClassicSpeech in the list. Press the Applications key or Shift+F10, then choose What's new.

NVDA opens the notes in a window titled "Changes for" followed by the version. You read it in browse mode, like a web page. Its Copy button (Control+Shift+C) copies the notes, and its Close button closes the window.

  • The Add-on Store offers What's new for a version of ClassicSpeech that it lists, so you can read about an update before you install it, and for a copy you installed from the Add-on Store.
  • It doesn't offer it on the Installed add-ons tab for a copy installed from an add-on file, which includes Check for Updates.... For that copy, the update offer described above shows each release's notes before you install.
  • NVDA 2025.1 through 2025.3 don't show these notes.

Where ClassicSpeech keeps its settings

Everything ClassicSpeech remembers is in one folder called ClassicSpeech, in NVDA's user configuration folder. For an installed copy of NVDA, that is %APPDATA%\nvda\ClassicSpeech. For a portable copy of NVDA, it is the ClassicSpeech folder inside the portable copy's userConfig folder. To open NVDA's user configuration folder, open the Start menu, then NVDA, then Explore NVDA user configuration directory, or type %APPDATA%\nvda in the Run dialog (Windows+R).

What the ClassicSpeech folder holds
File or folderWhat it holds
settings.iniEvery ClassicSpeech setting: the pages of General Settings and Web / Browse Mode Settings, verbosity profiles, the Token Editor, key labels, voice profiles, and which speech and sound scheme is active. For an installed copy of NVDA, its full name is %APPDATA%\nvda\ClassicSpeech\settings.ini. It has the same format as NVDA's own nvda.ini, and you can read it in Notepad.
SchemesOne folder for each speech and sound scheme, with its sounds. See Where schemes are kept.
nvda-settings-backup.jsonThe NVDA settings ClassicSpeech has changed, and the value each one had before. ClassicSpeech uses it to put NVDA back when you reset or remove ClassicSpeech. See NVDA settings ClassicSpeech changes.

The add-on's program files are in a different folder, %APPDATA%\nvda\addons\ClassicSpeech. NVDA's Add-on Store manages that folder; don't change it yourself.

Earlier versions of ClassicSpeech kept their settings in the [classicSpeech] section of NVDA's configuration file, nvda.ini. The first time this version starts, it moves them into settings.ini, and the next time NVDA saves its configuration, the section is removed from nvda.ini. Nothing else changes.

NVDA settings ClassicSpeech changes

Some ClassicSpeech settings change NVDA's own settings, which NVDA keeps in nvda.ini and in your configuration profiles:

  • Object presentation: Report object descriptions, Report tooltips and Report object position information follow the active verbosity profile. Report shortcut keys follows Speak hotkeys in on the Hotkeys page. Guess object position information when unavailable is on the Misc page.
  • Keyboard: Speech interrupt for typed characters and Speech interrupt for Enter key, on the Misc page.
  • Document formatting: every option on the Document Reading / Proofing and Web Element Reporting pages.
  • Browse mode: NVDA's options on the Browse Mode page.
  • Annotations and braille: Report 'has details' for structured annotations, Report aria-description always, and Braille report live regions, on the Web Element Reporting page.
  • Speech: when you choose another synthesizer for a scheme item, NVDA adds that synthesizer's default settings to its configuration if you have never used it. ClassicSpeech never saves a scheme voice or a voice profile as your NVDA voice settings.
  • General: Play sounds when starting or exiting NVDA, which ClassicSpeech turns off while the active speech and sound scheme has a sound for NVDA starts. See Replacing NVDA's own sounds.

Before ClassicSpeech changes one of these settings for the first time, it records in nvda-settings-backup.json whether the setting was set, and its value, in the configuration it changes: your normal configuration, or the configuration profile that was active. After each change, it records the value it gave the setting.

Earlier versions of ClassicSpeech did not record these values. When this version first starts, it records the Object presentation options that your saved ClassicSpeech settings show it set, as changed from NVDA's defaults. A reset then puts NVDA's defaults back for them: Report object descriptions, Report object position information and Report shortcut keys on, and Report tooltips off. Earlier versions left no record for the other NVDA settings, so check those in NVDA's own settings.

Earlier versions could also save a scheme item's voice, or a voice being previewed, as your NVDA voice settings for a synthesizer. This version no longer does. If a synthesizer sounds different from what you chose in NVDA, choose that synthesizer and check its voice settings: press NVDA+Control+V.

Resetting ClassicSpeech

Reset ClassicSpeech to put NVDA back the way it was before you installed and customized ClassicSpeech, for example before you remove it. Press NVDA+N, then choose Preferences, then ClassicSpeech, then Reset All ClassicSpeech Settings.... You can also assign a gesture to the Resets all ClassicSpeech settings and restores the NVDA settings it changed command.

Close the ClassicSpeech settings dialogs first. A dialog asks "Do you really want to reset all ClassicSpeech settings?", because you can't undo a reset. Press Yes to reset, or No, the default, to keep everything as it is. To keep your schemes or voice profiles, export your schemes and export your voice profiles first. When you press Yes, ClassicSpeech:

  1. puts back each NVDA setting it changed, with the value it had before, in your normal configuration and in each configuration profile where it changed one;
  2. deletes the ClassicSpeech folder, including settings.ini, every scheme and the sounds copied into your schemes, and any [classicSpeech] section an earlier version left in nvda.ini;
  3. starts again with its default settings;
  4. saves NVDA's configuration, so the reset lasts even if NVDA doesn't save its configuration when it exits.

If you changed one of those NVDA settings in NVDA's own settings after ClassicSpeech last changed it, the reset keeps your value, and the final message says how many settings it kept.

Removing ClassicSpeech

Remove ClassicSpeech in NVDA's Add-on Store: press NVDA+N, then choose Tools, then Add-on Store. On the Installed add-ons tab, select ClassicSpeech, press the Applications key, choose Remove, and restart NVDA when asked.

When NVDA restarts, ClassicSpeech cleans up before any add-on runs. It puts back the NVDA settings ClassicSpeech changed and deletes every ClassicSpeech setting, exactly as Resetting ClassicSpeech does, then NVDA saves its configuration. You don't need to reset before you remove ClassicSpeech, but a reset lets you check the result while ClassicSpeech is still installed.

  • Updating ClassicSpeech, with Check for Updates or by opening a new add-on file, keeps your settings.
  • Disabling ClassicSpeech in the Add-on Store keeps its settings, and the NVDA settings it changed stay as they are until you enable it again, reset it or remove it. The exception is Play sounds when starting or exiting NVDA: if ClassicSpeech turned it off for your scheme's start sound, it turns it back on, so NVDA plays its own start and exit sounds while ClassicSpeech is disabled.
  • If you copied your settings to NVDA's system configuration, for sign-in and secure screens, copy them again after removing ClassicSpeech: in NVDA's General settings, press Use currently saved settings during sign-in and on secure screens.

Removing ClassicSpeech settings by hand

Earlier versions of ClassicSpeech leave their settings behind when you remove them. The easiest way to remove those settings is to install this version, restart NVDA, then remove it again, or choose Reset All ClassicSpeech Settings first.

To remove the settings by hand instead, while ClassicSpeech is removed or disabled:

  1. Open NVDA's user configuration folder, as described above, and delete the ClassicSpeech folder.
  2. Open nvda.ini in that folder with Notepad. If it has a line that says [classicSpeech], delete that line and every line after it, up to the next line that starts with a single [. Lines that start with [[ belong to the section, so delete them too. Save the file.
  3. Press NVDA+Control+R once (Revert to saved configuration), so NVDA reads the edited nvda.ini, then press NVDA+Control+C to save it.
  4. Check the NVDA settings listed in NVDA settings ClassicSpeech changes, in NVDA's Object Presentation, Keyboard, Document Formatting and Browse Mode settings. If you kept a copy of nvda-settings-backup.json, it lists each setting ClassicSpeech changed. "before" shows its earlier value, and "set": false means NVDA's default.

To go back to all of NVDA's default settings, choose Reset configuration to factory defaults in the NVDA menu. That resets every NVDA setting, not only the ones ClassicSpeech changed.

Troubleshooting

  • Speech feels slow. In General Settings, clear Enable ClassicSpeech diagnostic logging on the Advanced page. On the Misc page, Prevent automatic speech interruptions also makes some speech wait for current speech to finish.
  • You want to compare with NVDA's normal speech. Clear Enable ClassicSpeech speech processing hook on the Advanced page, then check it again when you are done.
  • NVDA says too much or too little. Choose another verbosity profile or change its Spoken object details on the Verbosity page, and mute words you don't need in the Token Editor.
  • A key such as F12 no longer works in a program. See the note at the end of Speech history.
  • A scheme sound doesn't play. Check that Enable speech and sound schemes is checked and that the right scheme is active. Make sure the file is a WAV file and hasn't been moved; Play sound tells you if the file can't be found.
  • NVDA plays its own sound instead of yours. Check that Enable speech and sound schemes is checked and that the scheme with your sound is active. Item details names the NVDA option that turns the sound on. If NVDA can't play your WAV file, it plays its own sound.
  • Play sounds when starting or exiting NVDA is off in NVDA's General settings. Your active scheme has a sound for NVDA starts, so ClassicSpeech plays the start and exit sounds itself. See Replacing NVDA's own sounds.
  • NVDA's speech cuts off a ClassicSpeech message, such as the speech hook loaded message. Check Give ClassicSpeech messages priority over NVDA speech on the Misc page.
  • A scheme you copied into the Schemes folder yourself isn't used. Open Speech and Sound Schemes and choose it in Active scheme. A scheme folder needs its scheme.json file. To add a scheme someone sent you as a file, Import scheme is easier.
  • An item doesn't use the other synthesizer you chose. ClassicSpeech tells you when it can't load a synthesizer, and uses your active synthesizer instead. The active synthesizer is also the fastest choice.
  • You want NVDA exactly as it was before ClassicSpeech. Choose Reset All ClassicSpeech Settings, or remove ClassicSpeech. See Resetting ClassicSpeech.
  • Check for Updates says GitHub could not be reached. Check your internet connection; a firewall or proxy may block api.github.com. You can always download new versions from the releases page.

Reporting a problem

Report problems on the GitHub page where you got ClassicSpeech. Please include:

  1. your NVDA and Windows versions;
  2. your synthesizer and voice;
  3. your verbosity profile and, when it matters, the voice profile category;
  4. the exact steps that cause the problem;
  5. what you expected to hear, and what you heard;
  6. the relevant part of the NVDA log, with personal information removed. Open the log from the NVDA menu: Tools, then View log.

Never include passwords, access tokens or other private information in a report.
