# ClassicSpeech 2.02

## What's new

- Updated the Spanish translation contributed by Luis Carlos (luiscarlos2000), with minor translation corrections.

## Scope

This is a Spanish-language update only, based on stable ClassicSpeech 2.01. Speech processing, voice routing, settings behavior, and update-channel defaults are unchanged. It does not include development-only features.

## Installation and verification

Download `ClassicSpeech-2.02.nvda-addon` and its `.sha256` sidecar from this release. The sidecar contains the package checksum. Open the add-on to use NVDA's normal installation and compatibility confirmation.

The packaged user guide and manifest changelog describe this update. Automated catalog and archive checks do not replace live NVDA language, speech, or installation acceptance testing.
